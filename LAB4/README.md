# LAB4 — Entity-Relationship Model and PL/SQL (Procedures, Functions, and Packages)

## Description

This lab introduces a new data model for a **university system** (schema **UN**). It includes creating the tablespace and schema, the entity-relationship model's tables with their **primary keys, foreign keys, and sequences**, **CHECK** constraints, and the development of **PL/SQL procedures, functions, and packages** for data insertion.

## Contents

| File | Description |
|---|---|
| `1_UN_schema_and_tablespaces.sql` | Creates the **UN** tablespace and schema |
| `2_Entity-relationship_model_tables.sql` | Tables of the entity-relationship model (e.g. `university`) |
| `3_Pk-fk_and_sequence.sql` | Primary keys, foreign keys, and sequences |
| `4_Create_all_check_constraints.sql` | `CHECK` constraints on the tables |
| `5_Procedures_functions_packages.sql` | PL/SQL procedures, functions, and packages for data insertion |
| `BD_LAB4-Pgina-1.drawio.pdf` | Entity-relationship model of the lab |
| `Evidence_Databases.pdf` | Execution evidence in Oracle SQL Developer |
